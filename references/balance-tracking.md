# 余额追踪约定

`/root/.hermes/data/balance.jsonl` — 个人资产余额快照。

## 规则

1. **仅每月发薪日记入**：一条 JSONL，记录发薪日各账户余额总额。不追加日常消费。
2. **大额一次性支出用 meta 行**：`{"type": "meta", "expense_xxx": 金额, "date": "YYYY-MM-DD", "note": "说明"}` 记在首部，不记入薪资行。
3. **日常消费不碰此文件**：三餐、购物、打车——不记。记了数据就偏，因为不会每笔消费都报。
4. **发薪日追加**：新发薪日 → append 新行到末尾。发薪日约每月 5 号（上月 26 至当月 25 工资周期）。

## 文件结构

```
{"type": "meta", "rule": "仅记录每月发薪。不追日常消费。发薪日 append 一行，其他支出不碰此文件。"}
{"date": "2026-07-03", "total": 169312.87, ...}
```
