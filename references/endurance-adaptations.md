# 耐力训练生理适应

> CTL 持续拉高后，身体发生哪些具体变化？燃脂效率是否提升？

## 核心概念

| 术语 | 含义 |
|------|------|
| CTL (Chronic Training Load) | 长期训练负荷，42 天指数加权平均。反映耐力训练"底子" |
| ATL (Acute Training Load) | 7 天急性负荷。登山日 ATL 飙升 110+ |
| ACWR | 急性/慢性负荷比。警戒线 >1.5，高风险 >2.0 |
| TSB (Training Stress Balance) | CTL - ATL。正值=准备就绪，负值=疲劳中 |

## CTL 提升后的生理适应

以下机制均在多项肌肉活检和血液指标研究中得到证实（主要文献：Holloszy & Coyle 1984, Hawley 2002, Coffey & Hawley 2007 等）。

### 1. 线粒体密度增加

- **机制**：PGC-1α 通路被反复高强度代谢刺激持续激活 → 线粒体生物合成加速
- **量级**：久坐者转规律训练 12-20 周，线粒体密度可增 50-100%。但需要大训练量（周 6-8 小时以上）
- **实际意义**：CTL 从 50 升到 70 级别，"显著增加"比较准确，"翻倍"说过头了
- **后果**：同样的功率输出，每分钟氧化更多脂肪酸，乳酸阈值推后

### 2. 毛细血管化（Capillarization）

- **机制**：VEGF 信号通路被反复局部缺氧刺激激活 → 毛细血管向肌纤维周围出芽
- **量级**：毛细血管/肌纤维比显著上升，已被活检证实
- **后果**：氧和脂肪酸从血管到线粒体的扩散距离缩短，提取效率提升

### 3. 脂肪动员与氧化敏感化

- **β-肾上腺素受体密度上调**：同样肾上腺素浓度，脂肪细胞释放更多脂肪酸
- **HSL（激素敏感性脂肪酶）活性增强**：脂肪细胞内甘油三酯分解加速
- **ATGL（脂肪甘油三酯脂肪酶）活性升高**：HSL 的搭档酶，协同增强脂解
- **脂肪酸转运蛋白（FAT/CD36, FABPpm）表达上调**：脂肪酸从血液进入肌细胞更快
- **后果**：同一强度运动时，脂肪供能比例升高，肌糖原消耗速率下降

### 4. Crossover 点右移

- **概念**：运动强度递增时，从脂肪供能主导切换到碳水供能主导的转折点
- **训练效应**：高 CTL 将这个切换点推到更高强度。原来心率 120-130 切碳水，训练后可能推到 140+
- **注意**：具体心率数字取决于个体最大心率和训练状态，无法给出通用数值。方向正确，数字不该乱给
- **后果**：爬同一个坡，原来已经切碳水模式，现在仍在高效燃脂区

### 5. 运动经济性（Exercise Economy）

- **本质**：同样的绝对功率输出，消耗更少氧气和热量
- **是好事也是坏事**：
  - 好事：可以走更远/更陡/更久
  - "坏事"（减脂视角）：同样 12km 香巴拉比没训练时烧得更少
- **补偿**：高 CTL 的实际意义是人会主动走更长路线——经济性提 10%，路线长 50%，总燃脂量上升。不要把人当固定距离的机器算

### 6. 恢复加速（重复回合效应 Repeated Bout Effect）

- **核心机制**：
  - 细胞骨架蛋白 desmin 适应性增强，肌纤维膜抗机械损伤能力提升
  - 炎症因子 IL-6、TNF-α 释放幅度衰减
  - 皮质醇分泌反应幅度降低，峰值更早回落
- **已被证实**：肌肉活检 + 血液指标反复验证（Clarkson & Hubal 2002, McHugh 2003）
- **后果**：同样 12km 登山，肌肉微损伤减半，ACWR 高位窗口从 3 天缩到 1-2 天，睡眠不再被交感神经劫持

## 登山后的急性反应（非适应）

高强度登山当天的急性生理反应，不是 CTL 高的福利，是每人都有的负担：

| 现象 | 机制 | 持续时间 |
|------|------|----------|
| 体重上涨 0.5-1.5kg | 肌纤维炎症水肿 + 糖原超量恢复绑水 | 48-72h |
| 睡眠碎片化 | 交感神经持续兴奋，皮质醇压褪黑素 | 24-48h |
| 深睡时长下降 | ATL 110+ 副交感让不了路 | 1-2 晚 |
| BIA 体脂偏高 | 水肿改变肌肉导电率，秤误算 | 48-72h |

ACWR 高位和睡不着不是因果关系——它们是同一个根（肌纤维修复负荷 + 交感神经过度兴奋）的两片叶子。

## 与低强度有氧的区别

| | 高强度登山 | 低强度散步 |
|---|---|---|
| MET | 6-7 | 3-4 |
| 脂肪供能比 | ~40-55% | 65-75% |
| 糖原消耗 | 400g+ / 次 | 15-25g / 次 |
| 需要补快碳 | 是，1 小时内 | 否 |
| 需要恢复日 | 是，2-3 天 | 否 |
| 打开肌糖原窗口 | 是 | 否 |

散步燃脂比虽高但因总量小对减脂贡献有限——优势在于不产生恢复债务，可以每天做。
