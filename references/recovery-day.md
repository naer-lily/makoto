# 登山次日恢复协议

> 高强度登山后 24-48 小时的生理特征和应对策略。

## 次日体重上涨：正常生理现象

登山次日体重上涨 0.5-1.5 kg 是正常的水潴留，不是脂肪：

1. **肌肉炎症水肿**：下坡离心收缩微撕裂肌纤维，修复液囤积 200-800g
2. **糖原超量恢复**：碳水大量摄入后，每克糖原绑 3-4g 水，轻松 200-400g
3. **BIA 体脂秤被愚弄**：炎症水肿改变肌肉导电率，秤把更导电的肌肉误算成体脂。体脂率读数会上涨 0.3-1%

2-3 天后炎症消退、糖原回到正常水位，真实体重才显露。

## 体重趋势：看低水位线，不看峰值

每次登山后体重弹到相似数字（如 72.7）不代表停滞。要看**低水位线**——每次登山前的晨起空腹体重：

```
6/5: 72.6 → 6/12: 72.0 → 6/18: 71.5 → 6/22: 71.3 → 6/27: 71.8
```

低水位一个月下了 1.3 kg，趋势健康。登山后的肿胀峰值随强度增大而升高，不代表退步。

## 次日睡眠：深睡被打碎

ATL 110+ 后交感神经刹车失灵，皮质醇压褪黑素。

**机制链**：12km 负重 → 肌纤维微损伤 → 炎症因子（IL-6, TNF-α）释放 → 交感神经持续兴奋 → 皮质醇夜间不降 → 入睡困难、浅睡多、深睡碎片化。

- 深睡连续性下降、频繁渴醒是正常反应——不是你去山上跑了一趟回来就失眠了，是身体在修
- ACWR 高位和失眠不是因果关系，它们是同一根神经内分泌应激链的两片叶子
- 生长激素分泌打折，但不导致肌肉分解（热量吃够了）
- 48-72 小时消退，第二晚应该比第一晚好
- 真正警戒信号：连续两晚深睡 < 1.5h + 静息心率比基线高 10+
- 高 CTL 后同样 12km 刺激，皮质醇反应幅度会衰减——睡眠质量随之改善

## 恢复日碳水时序：早上必须吃碳水

登山次日早晨碳水严重不足（<15g）是常见但必须避免的错误。身体刚经历 6 小时糖原耗竭 + 肌肉微撕裂，晨起空腹仍处于分解代谢状态——不给碳水，身体继续拆蛋白供能。**早上第一顿必须包含 ≥50g 碳水**，上午累计 ≥80g。

典型错误时间线（今天实际发生）：
- 05:00 蛋白棒 25g（碳水 9g）
- 06:00 酪蛋白粉 40g（碳水 2g）  
- 07:00 羊杂汤（碳水 2g）
- → 早上 7 点碳水仅 13g，用户自己发现了不对劲

正确做法：醒来第一顿就该碳水蛋白一起上，面包/馒头/米饭 ≥50g 碳。蛋白分散到后续餐次补。

## 恢复日宏量方案

恢复日不是减脂日——身体是工地，热量是建材。

| | 克数 | 热量 | 占比 | 原则 |
|---|---|---|---|---|
| 蛋白质 | ≥158g (2.2g/kg) | 632 | ~38% | 硬线，不够就酪蛋白粉 |
| 碳水 | ~150g | 600 | ~36% | 不多给，昨天糖原已灌满 |
| 脂肪 | ~45g | 405 | ~24% | 别砍太低，细胞膜修复要磷脂 |
| **合计** | | **~1640** | | 缺口 200-300，不追大缺口 |

- 总摄入 1600-1700 kcal
- NETEE 1927，缺口控制在 200-300
- 第二天回归工作日 500-800 缺口节奏
