# 自制批量食物注册

当那尔さん做了一大锅东西分装多份时，注册食物的流程：

## 步骤

1. **确认配料和总量**：用户报所有原料的克数（如 500g 番茄意面酱 + 500g 洋葱 + 250g 鸡胸肉 + 20g 油）
2. **计算总营养**：
   - 每样配料 × 克数 → 汇总总热量、总蛋白、总碳水、总脂肪
   - 分装 N 份，每份克数（如 4 份 × 250g = 1000g 总量）
3. **换算 per-100g**：总营养 ÷ 总克数 × 100
4. **注册食物**：`makoto food add "自制XXX" --calories X --protein X --carbs X --fat X --note "配料+分装信息"`
5. **使用时**：`makoto diet log -f "自制XXX" -g 250`（按每份克数记）

## 名称规则

- 用 `"自制番茄肉酱"` 而非 `"自制意大利面酱"`——准确描述内容物
- 备注里写清配料和分装：`"500g番茄意面酱+500g洋葱+250g鸡胸肉+20g油，分4份~250g/份"`

## 示例

```bash
# 番茄肉酱：番茄酱500g + 洋葱500g + 鸡胸肉250g + 油20g = 总重约1270g
# 总热量：225+200+275+180=880kcal，蛋白69g，碳水88.5g，脂肪23g
# per-100g：69.3kcal, 5.4g蛋白, 7.0g碳水, 1.8g脂肪
makoto food add "自制番茄肉酱" \
  --calories 69 --protein 5.4 --carbs 7 --fat 1.8 \
  --keywords "意面酱,肉酱,自制,减脂" \
  --note "500g番茄意面酱+500g洋葱+250g鸡胸肉+20g油，分4份~317g/份"
```

## 注意事项

- 如果用户只给了总份数和每份克数但未确认总量，**先问清楚实际总重再注册**
- 注册时用实际总重反推 per-100g，不要用估算的总重
- 食物名称不要和库里的「番茄酱(ketchup)」混淆——本质不同的东西必须用不同名字

## 肉饼烹饪技巧

### 生抽/酱油淋锅时机

煎肉饼时如果要加酱油调味，不要一开始就淋——那时候肉饼还没封住，酱油渗进去出不了焦香，只剩咸味。

正确时机：两面煎定型、微黄之后。转小火（酱油焦化太快会苦），沿锅边淋半勺，滋啦一声翻面裹匀，再大火收 10 秒出锅。

### 紫薯做肉饼的风味问题

紫薯的植物甜和鸡胸肉的寡淡之间缺乏过渡层，微甜肉饼不是主流风味是有原因的。如果想继续紫薯路线：
- 煎制时淋半勺生抽或鱼露——咸鲜进来后甜就变成焦香底味而不是主调
- 换土豆或山药更自然——中性碳水跟肉饼融合度更高
- 紫薯留着单独吃反而出彩
