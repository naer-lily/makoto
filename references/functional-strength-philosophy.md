# 功能性力量训练哲学

## 用户的核心诉求

用户追求的不是肌肥大（健美式），而是实用性肌肉：
- 闪电般的刺拳（拳击：前臂+三角肌爆发力、核心抗旋转）
- 跑酷攀岩（相对力量 = 力/体重比、握力）
- 体操运动员的能力（高强度自重控制力、空间感知）

三种能力共享前提：**力量体重比**。每多 1kg 无用体重都是负担。

## 与肌肥大的区别

| | 肌肥大 | 功能性 |
|---|---|---|
| 目标 | 绝对尺寸和分离度 | 力/体重比和神经效率 |
| 动作 | 孤立单关节为主 | 复合闭链为主 |
| 负荷 | 中等重量高容量 | 自重为主+爆发力 |
| 适用性 | 视觉审美 | 运动表现 |

## 当前训练对标

用户现有训练（保加利亚深蹲、澳式引体、臂屈伸、俯卧撑）本质上已经是复合功能性动作。框架不需要改，只需补充：

- **爆发力**：击掌俯卧撑、跳蹲、药球砸地
- **握力**：死挂、毛巾引体
- **核心抗旋转**：Pallof press（弹力带代替龙门架）

## 格教练（Greg Doucette）方法论对照

### 与用户体系的契合点
- 热量赤字追踪 ✓（makoto = Greg 的记录法）
- 高蛋白：每公斤 2.2g（用户 1.6-2g 在范围内）
- 有氧每周 150min+ ✓（拳击+登山远超）
- 低卡高饱腹感食物替换 ✓
- 触发食物管理 ✓（用户的"矜持"系统）

### 差异
- Greg 主张每餐带蛋白、每天 4-5 餐；用户两到三顿大餐模式
- Greg 反对间歇性禁食

### 关键数字
- 增肌仅需每天约 **30 kcal** 盈余——不是几百大卡
- 力量训练一次平均消耗 150-300 kcal
- 每周减重速度：体重的 0.5%-1%，不超过 1%
- 男性体脂目标：15%（Greg 建议"梦想身材的一半好"）

## 训练频率原则

按 Greg 三原则：每肌群每周两次 + 10-20 正式组 + 渐进超负荷。

用户的"依从性优先"版本（不动脑子的固定周循环）：

| 天 | 动作 | 时长 |
|---|---|---|
| 周一+周四 | 保加利亚深蹲 + 单腿臀桥 + 弯举 + 臂屈伸 | 20min |
| 周二+周五 | 俯卧撑 + 推举 + 划船 + 面拉 + 仰卧举腿 | 20min |

拳击日跳过当天力量，登山替代任一。每次 20 分钟，每肌群两次。
