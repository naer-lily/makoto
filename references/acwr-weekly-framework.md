# ACWR 与周计划框架

## ACWR 标准范围

学术界通用风险分级：

| ACWR | 风险等级 |
|:--:|:--|
| < 0.8 | 训练不足 |
| 0.8–1.3 | 正常/sweet spot |
| 1.3–1.5 | 升高风险 |
| > 1.5 | 高风险 |

**关键**：< 1.3 才是正常范围，不是 < 1.5。1.5 已经是高风险区的下界。别把 ACWR 和 缺口 两个不同的数字搞串——用户纠正过这个混淆（「我tm说缺口是正常范围，ACWR小于1.3才是正常范围啊」）。

## ACWR 个体化评估

那尔さん的耐受基线高于通用人群。
- 运动前 ACWR 1.2 为常态
- 运动后 ACWR 1.6 为可控峰值
- 登山日后运动后 ACWR 经常到 2
- ACWR 在他手里是拉 CTL 的杠杆，不是被动报警器

评估前必须先问用户的实际基线和历史峰值。如果用户明确说"我要的就是ACWR飙高"，尊重他的判断，不要替他决定"太危险了"。

## 替代规则

天气取消登山时的室内替代，不能 1:1 复制时长和强度：

- 登山有平路有下坡心率波动；爬楼是连续垂直负荷，拳击 84min 是超长时长
- 替代原则：降一档。拳击 60min 封顶或散步 90min 即可
- 把"替代"当成"加倍"是 ACWR 飙高的根因

## 驻场后训练窗口（2026-07-06起）

那尔さん驻场邮储大厦，距家步行1分钟/500米，工时8:30-18:10（午休11:30-13:30）。

可用训练窗口：
- **午间（11:30-13:30）**：步行1分钟回家，可安排拳击/有氧40-60min。心率自由（他本人基线150+），不限制时长。打完后冲澡吃饭，13:30回工位
- **晚间（18:10后）**：下班步行1分钟到家，6:30前可开始力量训练。完整2h窗口
- **早间（07:00-08:30）**：理论上可晨练，但用户倾向于多睡而不是早起训练

中午+晚间双练可行性：间隔5-6h无AMPK-mTOR冲突。这不是特殊训练模式，是标准组合训练安排。

## 力量缺课与疲劳管理

爬山/高强度有氧后 DOMS 未清 → 顺延力量日到周二或周三，不硬撑。

- 周一腿还酸/胀/无力 → 保加利亚深蹲和水桶深蹲直接跳过
- 顺延不是偷懒，是避免训练质量打折 + 防止进一步损伤
- 跳过一次力量后，不要在周末翻倍补偿
- 疲劳链条：爬山 → DOMS延续 → 跳过力量 → 周末焦虑补偿（加码）→ ACWR 失控
- 破局：接受缺课，不补偿。力量频率靠的是周一+周四的规律性，不靠单次加倍

## CTL / ATL 计算公式与陷阱

### 核心公式

CTL 是 42 天指数移动平均（EMA），非等权重窗口：

```
CTL_today = CTL_yesterday + (TL − CTL_yesterday) / 42
```

第 n 天前的 TL 对当前 CTL 的残留贡献：

```
贡献 = TL × (1/42) × (41/42)^n
```

### 42 天窗口边际衰减（λ = 1/42）

| 天数前 | 衰减因子 | 600 TL 残留 |
|:--:|:--:|:--:|
| 0（当天） | 1/42 = 0.0238 | 14.3 |
| 21 | 0.0143 | 8.6 |
| 42 | 0.0087 | 5.2 |
| 84 | 0.0031 | 1.9 |

### 关键理解

- **CTL 不会骤降**：42 天前的大 TL 滚出窗口时，每天只衰减约 0.12，不是一天掉 5。连续几周不训练才会显著下降。
- **CTL 涨得慢、跌得也慢**：EMA 天性。单次 630 TL 的大日子当天贡献 ~14.8，日常训练日 TL 50-80 贡献 ~1.2-1.9。
- **规律动是 CTL 最强的锚**：只要每周保持训练，新 TL 进 > 旧 TL 自然衰减出。

### 常见错误

1. **用不切实际的 TL 举例**：普通训练日 TL 50-80，高强度登山 200-630。用 1500 TL 做例子是纯属扯淡——那得双倍 Ironman。
2. **把 42 天衰减当断崖**：EMA 是平滑曲线，不是"第 43 天突然归零"。42 天前一天的贡献还剩约 1/e ≈ 37%。
3. **混淆 TL 和 kcal**：TL 是基于心率/EPOC 计算的训练负荷分数，不是千卡。手环的 TL 通过 Firstbeat EPOC 或 hrTSS 体系计算，是派生值而非直接测量。
